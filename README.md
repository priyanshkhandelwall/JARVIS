🤖 JARVIS: Python-Based Voice Assistant for Desktop Automation

--- 

📌 Project Description

JARVIS is a desktop-based voice assistant built using Python that responds to spoken commands and performs a wide range of automation and productivity tasks. It uses speech recognition and text-to-speech to enable natural interaction between the user and the system.

The assistant can open and close applications, search the web, control media playback, fetch live information, manage reminders, schedule tasks, and perform system-level operations. This project demonstrates practical use of Python libraries for automation, voice interfaces, and real-time user interaction.

---

❓ Key Features

🎙️ Voice-based interaction using speech recognition

🗣️ Text-to-speech responses for natural feedback

🖥️ Open and close desktop applications via voice commands

🌐 Google, YouTube, and Wikipedia search integration

⏰ Alarm, reminders, and daily task scheduling

🎵 Media playback and volume control

🌦️ Live weather and temperature updates

📰 News headlines on demand

📶 Internet speed testing

📸 Screenshot and camera control

🔔 Desktop notifications for tasks and updates

---

🛠️ Technologies Used

This project is developed using Python and the following libraries:

- Python 3
- pyttsx3 (Text-to-Speech)
- SpeechRecognition
- PyAutoGUi
- BeautifulSoup
- Requests
- Plyer
- Pygame
- Speedtest

---

▶️ How to Run the Project

1️⃣ Clone the Repository
- git clone <repository-url>
- cd Jarvis-Voice-Assistant

2️⃣ Install Required Dependencies

- Install all required Python packages using pip
- pip install pyttsx3 SpeechRecognition pyautogui requests beautifulsoup4 plyer pygame speedtest-cli

3️⃣ Run the Assistant
- python Jarvis_main.py

4️⃣ Activate JARVIS
- Say “wake up” to activate the assistant.
- Say “go to sleep” or “finally sleep” to stop it.
